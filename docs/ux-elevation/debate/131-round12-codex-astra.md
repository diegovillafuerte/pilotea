## 6. What only evidence can settle

- **Mounted recognition:** test the four states, especially amarillo and gris, at 60cm in day/night conditions with colour-vision diversity. Use the specified ≥95% identification and zero gris-as-rojo criteria.
- **Actual host coexistence:** replay tall offers, navigation banners, host gross-rate badges, layout changes and enlarged text; measure both overlap and necessary suppression.
- **Interaction behaviour:** verify drag versus system Back, inert taps, touch-through C6, its timeout, atomic state changes and accessibility hit regions.
- **Comprehension and setup:** measure understanding of net versus paid amounts, the two thresholds, import consequences, source discrepancies and install-to-first-value time.
- **Shipped rendering:** verify bundled fonts, numeric features and 13sp text on physical devices. The PNGs do not establish those results.
