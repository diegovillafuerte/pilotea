- The last three offers: 14:32 green (good) — taken; 12:10 red (bad) — let go; 11:48 the fare couldn't be read.
- A link to see the whole day; an account entry; bottom navigation with three tabs: Hoy, Ganancias, Comparar.

Write ONE self-contained HTML file named hoy.html in the current folder: a 393×852 phone screen (body exactly 393px wide, 852px tall, no outer page chrome), inline CSS only, Google Fonts allowed via @import, no images, no JavaScript. Make it the best, simplest, most professional design you can — the bar is the Uber Driver app.
