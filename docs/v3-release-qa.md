## 0.2.16 / 18 — Uber durations of an hour or more (2026-11-06)

Base **f8aaab8 (0.2.15 / 17)** on `feat/v3-redesign`. Built from the first real device run of 0.2.15.

**Device result for 0.2.15 (Galaxy S25, 2026-11-06 17:42–17:46):** 126 frames saved by the debug recorder, 8 cards in 10 appearances (H1 and the $148.16 Priority appeared twice). **Root cause (Codex Astra; its Python mirror reproduced all 126 recorded parses with zero mismatches):** Uber prints `1 h 23 min`; ML Kit reads `lh 23 min`, `5h4 min`, `4h46`, `lh5min`, `h lh5 min`, `t 4h46`. The TOTAL row was found by an unrestricted search (`(?<!\S)(\S{1,4}?)\s*min`), which read TOTAL 23 from `lh 23 min` and 25 from `lh 25 min`. The route-row grammar (`\S{1,4}`, no spaces) could not hold `lh 18`, `4h 46`, the `t ` icon prefix or the `kmn` unit, so H1 and H2 had no route; on H3 `lh5` was unread and recovered as 25 − 20 = 5, because the wrong TOTAL counted as read as printed. The legacy labeled route had dropped the hour since June: `minutesRegex.find` takes the first `N min`, so `Viaje: 1 h 18 min` read 18.

**Fix:** one complete-token hour decoder shared by both paths (`UberCardChecksum.hours`): `DIGIT{1,2} WS* [hH] WS* DIGIT{1,2}`, with l/L/I/| → 1 and O/o → 0 in the two components only, accepted iff 1 ≤ H ≤ 23 and 0 ≤ M ≤ 59, value 60·H + M. Each slot is identified whole first and decoded second. The TOTAL envelope is anchored at the row start (only the observed `cid ` may precede it), and an unread duration keeps the modern path. Route rows match whole; at most one space-separated icon prefix is removed (`t ` joins `e h`, `ad h`, `h`, `d`, `n`) and the entire rest is decoded (`h lh5` → 65; `lh 18` → 78, its l being the hour digit; glued `h6` stays unread and the unchanged rule recovers it). `kmn` is a distance-unit misread like `knm`; `(128 k)` stays rejected. Hour conversion is no repair; confusables set `REPAIR_CONFUSABLE`. Recovery rules are unchanged: a repaired `lh` TOTAL is never an operand, so an unread `lh5` can never become 5. Legacy: `partialLeg` reads the span from the `Viaje` label to the minute unit and, when it holds an hour marker, requires a complete hour duration (no suffix retry, no new icon stripping); `tripLegRegex`, `legRegex` and `unlabeledLegRegex` match the whole hour duration first; `cleanMinutes` sends hour tokens to the strict decoder and keeps its two-digit rule for minute-only tokens (`21l` → 21). DiDi is unchanged: its observed long-trip format is minutes only (`81 min (12.9 km)`, 18:05, read correctly by the unchanged parser), so its leg regex's suffix hazard is theoretical; revisit only if a DiDi card ever prints an hour token (TD-061).

**Round 2 (the same run's later cards, 18:09–18:12, and three verifier findings):** on 0.2.15 the later hour cards H4 UberX $284.08 (`1 h 29 min`), H5 UberX $228.38 (`1 h 19 min`) and H6 UberX $240.98 (`1 h 14 min`) again got no chip (round 1 already reads them).
