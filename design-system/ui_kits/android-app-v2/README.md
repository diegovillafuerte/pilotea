- `fixture.json` is the golden fixture (raw inputs only). `check-fixture.py` derives every displayed figure from it, asserts the strings in `index.html` and the spec, checks every chip's accessible name and every offer row against its state phrase, and fails on known stale strings and the old vocabulary. Run it after any edit:

```bash
python3 design-system/ui_kits/android-app-v2/check-fixture.py
```

- `_frame-contract.md` lists, per frame, the strings `check-fixture.py` asserts. It is derived from the checker's own expectations (`check-fixture.py --contract`), so regenerate it whenever the checker changes.
- Render every frame to PNG, then build the per-section contact sheets (`sheets.py` reads the frames from `$KOMPARA_OUT/frames`):

```bash
cd design-system/ui_kits/android-app-v2
python3 render-frames.py <out-dir>
mkdir -p <sheets-dir> && ln -sfn <out-dir> <sheets-dir>/frames
KOMPARA_OUT=<sheets-dir> python3 sheets.py
```
